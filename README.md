# DIGIT Institute — Corporate Training Page

A responsive corporate training landing page recreated for the JavaScript assignment using:
- HTML5 semantic elements
- Tailwind CSS CDN and custom CSS (`styles.css`)
- Basic JavaScript (`script.js`)
- Lucide icons CDN

## Features
- Responsive navigation with mobile menu toggle
- Corporate training hero section and benefits
- Workforce training solutions section
- Consultation form with browser validation and demo success message
- FAQ accordion (one item open at a time)
- Responsive footer with contact information

## Run locally
Open `index.html` in a modern browser with an internet connection (Tailwind and Lucide are loaded from CDNs).

## Note
The consultation form is a front-end demo only. It does not submit information to a backend service.
